# FolloFind をアプリストアに出す手順（初心者向け）

おすすめの順番は **① Google Play（Android）→ ② App Store（iPhone）** です。
Google Play のほうが費用が安く、パソコンが Windows でも進められます。

このフォルダの素材:
- `listing.md` … ストアに載せる文（アプリ名・説明文など。コピーして使えます）
- `feature-graphic-1024x500.png` … Google Play のいちばん上に出る横長の画像
- アイコン … `wp-content/plugins/sns-creator-search/assets/brand/follofind-icon-512.png`（512×512）

---

## 0. 始める前の確認（5分）

- [ ] サイトが **https://** で開ける（鍵のマーク）。まだなら、サーバーの管理画面で「無料SSL」を有効にする
- [ ] 最新のプラグイン（1.22.0 以降）を入れている
- [ ] WordPress の管理画面「発信者 → スマホアプリ」で「ホーム画面に追加できるようにする」にチェックが入っている
- [ ] プライバシーポリシーのページが公開されている（URLを控えておく）
- [ ] スマホでサイトを開き、「アプリとして追加」できることを確かめた

## ① Google Play（Android）

### 費用と期間の目安
- 登録料: **25ドル（1回だけ）**。クレジットカードで払います
- **個人**で登録した場合、公開の前に「12人以上に14日間続けて試してもらう」テストが必要です（Google の決まり）。
  **会社（法人）**で登録した場合は不要ですが、「D-U-N-S 番号」（会社の番号。無料で取れますが数日〜数週間かかります）が要ります
- 全体で、早くて **3〜4週間** ほど

### ステップ1: 開発者アカウントを作る（30分）
1. https://play.google.com/console にアクセスし、Google アカウントでログイン
2. 「個人」か「組織（会社）」を選ぶ
3. 名前・住所・電話番号を入れ、登録料（25ドル）を払う
4. 本人確認（身分証明書の写真など）を求められたら、案内どおりに出す。確認には数日かかることがあります

> ✅ ここまでできたら教えてください。

### ステップ2: アプリのファイルを作る（15分・PWABuilder）
1. https://www.pwabuilder.com/ を開く
2. 入力欄に **サイトのURL**（FolloFind は `https://follofind.com/`。転送元の `follofind.jp` ではなく、転送先の本番サイトを入れる）を入れて「Start」
3. 点数が出ます。赤い ✕ があっても、「Package For Stores」が押せればOK
4. 「Package For Stores」→ **Android** →「Generate Package」
5. 設定画面が出たら、次のように入れる
   - **Package ID**: `com.（サイトのドメインを逆にしたもの）.app`
     FolloFind は本番サイトが `follofind.com` なので **`com.follofind.app`**（あとから変えられないので、よく確かめる。`follofind.jp` は `follofind.com` への転送用）
   - **App name**: `FolloFind`
   - **Launcher name**（アイコンの下の名前）: `FolloFind`
   - **Signing key**: 「Create new」（新しく作る）のまま
   - そのほかは、そのままでOK
6. 「Download Package」で ZIP ファイルを保存し、パソコンで開く（展開する）

ZIP の中身:
| ファイル | 使い道 |
|---|---|
| `○○.aab` | Google Play に出すアプリ本体 |
| `signing.keystore` と `signing-key-info.txt` | **アプリの「鍵」。なくすと二度と更新できません。** USBメモリやクラウドなど、2か所以上に大切に保存してください |
| `assetlinks.json` | サイトとアプリのつながりを確かめるもの（中の値を次のステップで使います） |

> ⚠️ `signing.keystore` と `signing-key-info.txt` は、誰にも送らないでください（このチャットにも貼らないでください）。

### ステップ3: サイトにアプリのことを登録する（5分）
1. ZIP の中の `assetlinks.json` をメモ帳で開く
2. `"package_name"` のあとの値（例: `com.follofind.app`）と、
   `"sha256_cert_fingerprints"` のあとの `AB:CD:...` の長い値をコピー
3. WordPress の「発信者 → スマホアプリ」の
   - 「パッケージ名」に package_name の値
   - 「署名の指紋（SHA-256）」に長い値
   を貼って保存
4. 保存すると、サイトの直下に `.well-known/assetlinks.json` のファイルが自動で作られます（1.26.2〜）。画面の「確かめる」を押して（または `https://follofind.com/.well-known/assetlinks.json` を開いて）、文字が表示されればOK
   - 「ファイルを作れませんでした」と出たときは、画面に出る中身を、サーバーのファイルマネージャーで `.well-known/assetlinks.json` として置く

> この2つの値は「鍵」そのものではないので、このチャットに貼っても大丈夫です。確認を手伝えます。

### ステップ4: Play Console でアプリを作る（30分）
1. Play Console で「アプリを作成」
   - アプリ名: `listing.md` の「アプリ名」
   - 言語: 日本語 / アプリ / 無料
2. 左のメニューの「アプリのコンテンツ」（ポリシー）で、順番に答える（下の「答え方の例」を参照）
3. 「ストアの掲載情報」に入れる
   - 短い説明・詳しい説明: `listing.md` からコピー
   - アプリのアイコン: `follofind-icon-512.png`
   - フィーチャー グラフィック: `feature-graphic-1024x500.png`
   - スマホのスクリーンショット: 2枚以上（下の「スクリーンショットの撮り方」）

### ステップ5: テストに出す（個人アカウントの場合は14日間）
1. 「テスト」→「クローズド テスト」→ テスターのメールアドレスを **12人以上** 登録（家族・友人・発信者仲間など）
2. 「新しいリリースを作成」→ ステップ2の `.aab` ファイルをアップロード →「保存」→「審査に送信」
3. テスターに、届いたリンクからアプリを入れてもらう。**14日間、入れたままにしてもらう**
4. 14日たったら、Play Console の「製品版へのアクセスを申請」から申請する

### ステップ6: 公開後に1つだけ追加する（5分）
Google Play は、アプリにもう1つ「Google の鍵」を付けます。そのままだとアプリの上にブラウザのバーが出るので:
1. Play Console の「テストとリリース」→「設定」→「アプリの完全性」→「アプリの署名」を開く
2. 「アプリ署名鍵の証明書」の **SHA-256** の値をコピー
3. WordPress の「署名の指紋」欄に、いまの値の後ろに **カンマ（,）で区切って** 貼り足して保存

これで、アプリを開いたときにブラウザのバーが出なくなります。

## ② App Store（iPhone）

### 先に知っておくこと
- **Mac（パソコン）** と、Apple の開発者登録（**年会費**。金額は https://developer.apple.com/jp/programs/ で確認）が必要です
- サイトをそのまま包んだだけのアプリは、審査で「アプリならではの機能が少ない」と断られることがあります
- iPhone の人は、ストアを使わなくても Safari で「共有 → ホーム画面に追加」でアプリとして使えます（通知も届きます）

まず Google Play を公開し、利用者が増えてから iPhone に進むのがおすすめです。

### 大まかな流れ（進めるときは、一緒に細かく案内します）
1. Apple Developer Program に登録（Apple ID で申し込み。確認に数日）
2. PWABuilder で「iOS」を選んで、Xcode（Mac の無料ソフト）のプロジェクトをダウンロード
3. Mac の Xcode で開き、アプリの ID・アイコンを確かめて、App Store Connect にアップロード
4. App Store Connect で説明文・スクリーンショット（6.7インチと6.5インチなど）・プライバシーの答えを入れて、審査に出す

## 答え方の例（Google Play「アプリのコンテンツ」）

実際の運営に合わせて変えてください。迷ったら、その画面の質問をこのチャットに書いてくれれば一緒に考えます。

| 質問 | 答え方の例 |
|---|---|
| プライバシー ポリシー | サイトのプライバシーポリシーのURL |
| 広告 | 広告枠を使っているなら「はい、広告が含まれています」 |
| アプリのアクセス権 | 「一部の機能はメンバー登録が必要」→ テスト用のメンバーアカウント（メールアドレスとパスワード）を作って書く |
| コンテンツのレーティング | 質問票で「ユーザー同士の交流・ユーザーが投稿したもの（記事・質問箱）がある」に「はい」 |
| ターゲット ユーザー | 13歳未満は選ばない（例: 18歳以上） |
| ニュースアプリ | いいえ |
| データ セーフティ: 集めるデータ | 「メールアドレス」（メンバー登録・ログイン。任意）、「名前」（発信者の表示名。任意）、「アプリ内の操作」（閲覧・検索。おすすめと分析に使う） |
| データ セーフティ: 共有 | なし（利用者が同意して送る「お仕事の相談」などは、共有に当たりません） |
| データ セーフティ: 暗号化 | はい（https で送る） |
| データ セーフティ: 削除の依頼 | はい（メンバーページ・マイページから退会できる） |

## スクリーンショットの撮り方
1. スマホでサイトを開き、アプリとして追加して開く（下にタブが出ている状態）
2. トップページ・検索結果・発信者のページ・比べる画面などを、スマホのスクリーンショットで撮る
3. そのままアップロードしてOK（縦長の画像で、2〜8枚）
