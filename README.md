# SNS発信者検索サービス

SNSアカウントを登録しておき、「どんな発信者がいるか」を探せる検索サービスです。
WordPress のプラグイン **SNS Creator Search** として作っています。

> 全体の設計と今後の計画は [docs/design.md](docs/design.md) を見てください。

## できること（現在のバージョン 1.3.0）

- **記事の自動執筆・自動投稿**: AI（Anthropic の Claude）が、章立て（5〜7章・小見出し・チェックリストや表・まとめ）のしっかりした5000字前後のSNS運用コラムを書き、決めた時刻（初期: 1日2本、7時と19時）に公開。目次とタイトル入りのアイキャッチ画像を自動で付ける。執筆はまとめて依頼する方式（Message Batches API、料金半額、サーバーで待たない）。字数・見出しが足りない記事は使わない。スターター記事を5000字版に書き直すボタン、下書きで止めて運営が確認するモードつき。管理画面「発信者 → 記事の自動投稿」。APIキーは wp-config.php の `SNSCS_ANTHROPIC_API_KEY` か管理画面で設定
- **ヤフー風のポータル表示**: ページテンプレート「SNS検索ポータル（全幅）」（テーマの代わりにポータル形のヘッダー・フッターで表示）と、トップページ用の `[sns_portal_top]`（SNSタブつきの大きな検索窓、カテゴリ・地域、注目の発信者、急上昇、特集、新着、コラム、ログイン、カレンダー、トレンドワード、お知らせ、広告）。管理画面「発信者 → 集客・回遊」のボタン1つで作成し、ホームページに設定できる
- **マイリンク**: SNSのプロフィール欄に貼る「リンクまとめ」ページ（`/@hanako` など。IDは審査あり。決めるまでは紹介コードのURL）。スマホ向けの1枚のページにSNS・note/Brain・その他のリンク・最新の記事・お仕事の相談を大きなボタンで並べる。デザインは6種類。開かれた数は紹介リンク流入として数え、どのリンクが押されたかをマイページに表示。ページの下から「ほかの発信者を探す」「あなたもマイリンクを作る（招待リンク）」へ案内
- **SNS発信カレンダー**: 投稿予定・撮影・打ち合わせ・ライブ配信・締切などの予定を管理（月の表示、追加・変更・削除、完了チェック）。ログイン中はサーバーに保存し、当日の朝にメールでお知らせ。ログインしていない人はブラウザに保存。運営のイベントと、投稿のネタになる記念日も表示。トップページには `[sns_calendar_link]`（今日の日付・近い予定・「カレンダーを開く」ボタン）
- **あなたへのおすすめ（パーソナライズ）**: 見た発信者・滞在時間・読んだ記事・検索の条件から「好みの傾向」をブラウザの中に育て、「あなたへのおすすめ」と検索の「おすすめ順」を一人ひとりに合わせる。「この発信者を見た人は、こんな発信者も見ています」（同じ日に一緒に見られた組から予測）。傾向はサーバーに個人ごとに残さず、いつでもオフ・リセットできる
- **回遊のしかけ**: お気に入り（☆）・最近見た発信者、人気・急上昇の検索キーワード、0件のときの「条件をゆるめると○人」、パンくずと関連する特集、サイト内ナビ、記事やコラムの下のおすすめ
- **特集ページ（SEO）**: 「ジャンル×SNS×地域」の組み合わせごとのページ（`/find/instagram/料理/` など）を自動で作成。見出し・説明文・構造化データ・サイトマップつき。人数の少ないページは検索エンジンに載せない
- **ランキング**: 総合（先月からの上下つき・過去の月も見られる）・急上昇・招待（今月のアンバサダー）・新着。`[sns_spotlight]` で「今月の注目」
- **シェア画像と掲載中バッジ**: 名前・写真・順位入りのシェア画像（OGP）を自動作成。発信者が自分のサイトに貼れる「掲載中」バッジ（押されると紹介リンク流入として数える）
- **メールマガジン**: 登録の確認つき（ダブルオプトイン）。毎週「今週の注目」「新着」「好きなジャンル」「新しいコラム」「人気のキーワード」を自動で作って配信。配信停止はワンクリック
- **無料ツール**: エンゲージメント率の計算、SNS発信タイプ診断（結果をシェアできる）
- **発信者インタビュー**: 質問のひな形入りの下書きをボタン1つで作成。記事に発信者の紹介を付け、公開したら本人にシェアをお願いするメール
- **お仕事の相談**: 発信者が受け付けを選ぶと、ページに相談フォームが付く（発信者のメールアドレスは相手に見せない）。企業向けページ `[sns_business]`
- **お気に入り（表示順位）**: ページを見てお気に入りに登録した人数を、おすすめ順の10個目の点数に追加
- 管理画面「発信者 → 集客・回遊」で、上の機能ページをまとめて作成・設定できる
- **発信者仲間の招待（紹介ネットワーク）**: 発信者ごとの招待リンク（`/join/コード/`）と招待コード。招待された人が審査を通って掲載されると、招待した人の「紹介ネットワーク」の点数が上がる。招待された人がさらに誰かを招待した場合も、決めた段数（初期3段、最大5段）まで、深い段ほど小さく数える。マイページにX・LINE・Facebookの共有ボタン、そのまま使える招待文、段ごとの人数。3人以上招待すると発信者ページに「アンバサダー」バッジ。**招待は表示順だけに使い、お金などの報酬は出さない**
- **note・Brain へのリンク**: 発信者ページに「コンテンツ販売・ブログ」としてnote・Brainのリンクを目立つ形で掲載（URLを貼ってもアカウント名だけを取り出す）
- **SNS運用コラム**: カテゴリ「SNS運用コラム」の投稿を、検索結果の下・発信者ページの下・発信者マイページ・`[sns_columns]` に、SNSやジャンルが合うものから自動で表示。コラム記事の下には「この話題の発信者を探す」ボタンと広告枠。スターター記事6本を下書きで追加できる（管理画面「発信者 → SNS運用コラム」）
- **トレンド（全体・ジャンル別）**: X のトレンドのように、いま調べられている言葉を「総合」と「料理」「ゲーム」などジャンルごとのタブで順位表示（`[sns_trends]`）。急に増えた言葉には「急上昇」の印。キーワードを押すとそのジャンルの中で検索
- **トレンドを入口にする集客**: 言葉ごとのトレンドのページ（`/trends/おせち/`。検索エンジンからの入口）、ジャンルで急上昇した言葉を発信者に知らせるお知らせ、ジャンル内の順位が入る順位バッジ（カード型あり）、5問で好みの発信者3人がわかる「発信者診断」（結果を画像でシェア）
- **記事のおすすめアルゴリズム（Google × X × note）**: フォロー中・一緒に読まれた記事・好みのジャンル・話題・質の高い記事・新着から候補を集め、「最後まで読む確率」を予測して並べる（読了率・反応率・書き手の信頼・不正対策つき）。同じ書き手が続かない多様さとお試し枠、理由の表示、「興味がない」。毎晩、実際に読まれたかどうかから重みを学習し、良いときだけ使う。検索結果には、関連度と質で並べた記事も出る
- **集客の強化**: 「○○さんに似ている発信者」のページ（発信者の数だけ検索の入口）、Googleに人物・記事として伝える構造化データ、ジャンル別の月間アワード（ファン投票・受賞画像）、公式SNS（Threads・X）への自動投稿、ブログに貼れるランキング、発信者どうしのコラボ相手探し、LINEでのお知らせ
- **会員が作る入口と、続けたくなる仕組み**: 読者が作る「推しリスト」、発信者が答える「質問箱」（Q&A）、AIのプロフィール診断（無料ツール）、会員のレベル・連続記録・バッジ・友だち招待、毎月の報道向け発表文とプレス・データのページ
- **規約ページ**: 利用規約・プライバシーポリシー・利用上の注意事項を、このサイトの機能に合わせた文面で作成（管理画面「発信者 → 規約ページ」）。登録画面の同意欄と、検索ページ・マイページの下からリンク
- **広告枠**: 画像＋リンク、アフィリエイトのHTMLコード、Googleアドセンスのコード、コンテンツ販売（Brain・Tips などの商品カード）を登録するだけで、決まった場所に控えめに表示（管理画面「広告枠」）。すべての広告に「広告」ラベル付き。表示回数・クリック数の集計、掲載期間、表示の割合、ads.txt の設定つき
- **発信者ページをハブにする機能**: 6つのSNSに加えて、ブログ・企業サイトなど「その他のリンク」を5つまで掲載。発信者がマイページから記事を書ける編集画面（新規・変更とも運営の審査あり、管理画面「発信者 → 記事の審査」）。記事の下には書いた人の紹介・SNS・リンクを表示
- **総合的な表示順位（おすすめ順）**: 紹介リンク・フォロワー・ページ閲覧・滞在時間・リンクのクリック率・記事の活動・発信者自身のサイトの利用日数・利用時間・紹介ネットワーク（招待した発信者）の9つの点数を重み付けして決定。最近の動きほど重く数え、機械的な水増しの疑いは自動で点数を下げて「要確認」に表示。発信者マイページに「あなたの分析」、発信者ページに「似ている発信者」、`[sns_recommended]` で「おすすめの発信者」
- **紹介リンクとおすすめ順**: 掲載中の発信者に専用の紹介リンク（`/r/コード/`）を発行し、リンク経由の流入人数を数える。検索結果の「おすすめ順」は、①紹介流入と②フォロワー数の順位を1:1で合わせた総合点で並ぶ（管理画面「発信者 → 表示順の設定」で重みを変更可）
- **発信者本人による登録・変更**: 発信者が会員登録し、マイページから掲載内容を申請。新規登録も変更も **運営の審査を通ったものだけ** が公開される
- **審査画面**（管理画面「発信者 → 審査」）: 申請の一覧、現在の内容と申請内容の比較（変わった項目は黄色）、承認／差し戻し（理由つき）
- **お知らせメール**: 申請が届いたら運営へ、承認・差し戻しの結果は発信者へ
- **掲載停止**: 発信者はマイページからいつでも掲載をやめられる（審査なし）
- **退会**: 発信者はマイページからいつでも退会できる（パスワードの再入力と確認が必要）。アカウント・掲載ページ・SNSアカウント・写真・申請の記録・紹介リンクとその記録をすべて削除し、本人と運営にメールで知らせる
- **運営による直接登録**（管理画面）: 名前・紹介文・写真・ジャンル・地域と、複数のSNSアカウント（SNSの種類 / ハンドル / URL / フォロワー数）
- **対応SNS**: X / YouTube / Instagram / Threads / TikTok / Substack
- **検索画面**: SNSごとの **インデックス（見出しタブ）** で切り替え。各タブに該当人数を表示。キーワード、ジャンル、地域、フォロワー数の範囲で絞り込み。フォロワー順・新着順・名前順に並べ替え
- **発信者ごとの紹介ページ**: SNSアカウントの一覧を自動で表示
- **CSV一括登録**: たくさんの発信者をまとめて登録
- **検索API**: 将来アプリなどから使える `/wp-json/snscs/v1/creators`
- 同じSNSアカウントを2人の発信者に重複して登録できないようにする仕組み

## 使い方

### 1. インストール
1. `wp-content/plugins/sns-creator-search` フォルダを、WordPress の `wp-content/plugins/` に置く
2. 管理画面の「プラグイン」で **SNS Creator Search** を有効化する
3. 管理画面の「設定 → パーマリンク」で「投稿名」などを選んで保存する（発信者ページのURLを有効にするため）

有効化すると、ジャンルと地域がまだ1つも無い場合だけ、よく使うもの（ジャンル10個・地域8個）が自動で入ります。管理画面の「発信者 → ジャンル」「地域」で自由に変更できます。

### 2. 検索ページを作る
固定ページを新規作成し、本文に次の1行を書いて公開します。

```
[sns_creator_search]
```

1ページに表示する人数を変えたいときは `[sns_creator_search per_page="30"]` のようにします。

### 3. 発信者マイページを作る
固定ページ（例: タイトル「発信者マイページ」）を作り、本文に次の1行を書いて公開します。

```
[sns_creator_portal]
```

- ログインしていない人には「ログイン」と「新規登録」が表示されます。
- 発信者がログインすると、掲載状況・審査状況と、登録内容の入力フォームが表示されます。
- 発信者は WordPress の管理画面には入れません（このページだけで完結します）。

申請が届くと、管理画面の「発信者 → 審査」に件数が表示され、サイト管理者のメールアドレスにお知らせが届きます。

### 4. 運営が発信者を登録する（任意）
- **1人ずつ**: 管理画面の「発信者 → 発信者を追加」。画面下の「SNSアカウント」欄に入力します。
- **まとめて**: CSVを用意し、サーバーで次のコマンドを実行します（[WP-CLI](https://wp-cli.org/) が必要）。

  ```
  wp snscs import creators.csv
  ```

  CSVの形式は [samples/creators-sample.csv](samples/creators-sample.csv) を見てください。
  1行が1アカウントで、同じ名前の行は同じ発信者としてまとめられます。ジャンルと地域は `|` で区切ると複数指定でき、無いものは自動で作られます。
  同じCSVをもう一度取り込んでも、発信者が二重に登録されることはありません。

### 5. 広告を出す
1. 管理画面「広告枠 → 広告を追加」で、種類（画像＋リンク／HTMLコード／Googleアドセンス）を選び、画像とリンク、またはコードを貼り付ける
2. 「表示する場所」を選んで「公開」を押す
3. 検索結果ページの枠（一覧の上・一覧の途中・一覧の下）は自動で表示される。トップページの枠は、表示したい場所に次のショートコードを書く

```
[sns_ad slot="top_side"]     （右上の四角い枠）
[sns_ad slot="top_infeed"]   （コンテンツの間の横長の枠）
```

Googleアドセンスを使う場合は「広告枠 → 設定」で `ads.txt` の内容と、審査用の `<head>` のコードを貼り付ける。

### 6. 規約ページを作る
管理画面「発信者 → 規約ページ」で運営者名・所在地・お問い合わせ先・裁判所・制定日を入れて「3つのページを作成」を押す。最初は下書きで作られるので、内容を確認してから公開する。空欄の項目は【運営者名】のように残るので、ページを編集して埋める。フッターに置くときは `[sns_legal_links]` を使う。

### 7. SNS運用コラムを書く
1. 管理画面「発信者 → SNS運用コラム」で「スターター記事を下書きで追加」を押すと、6本の記事が下書きで入る。確認して公開する
2. 新しく書くときは「投稿 → 新規投稿」で、カテゴリ「SNS運用コラム」、「対象SNS」、「ジャンル」を選ぶ
3. トップページなどに一覧を出すときは `[sns_columns count="6"]`（SNSをしぼるなら `sns="instagram"`）

### 8. 集客・回遊の機能を使う
1. 管理画面「発信者 → 集客・回遊」の「機能ページをまとめて作成」を押す（ランキング・特集・無料ツール・お気に入り・メールマガジン・企業の方へ）
2. 作られたページをメニューに追加する（「会員ページ」は読者の登録・ログインと、フォロー中の新着・ブックマークの画面）
3. トップページに `[sns_calendar_link]`（カレンダーへのリンク）、`[sns_for_you]`（あなたへのおすすめ）、`[sns_spotlight]`（今月の注目）、`[sns_trending]`（人気のキーワード）、`[sns_feature_links]`（人気の特集）を置く
4. メールマガジンは「発信者 → メールマガジン」でテスト送信して確認してから、「集客・回遊」で自動配信をオンにする
5. シェア画像に日本語を入れるには、サーバーに日本語フォントが必要（無ければ「集客・回遊」でフォントファイルの場所を指定するか、プラグインの `assets/fonts/` に .ttf / .otf を置く）

### 9. 検索アルゴリズム（学習）を使う
1. 管理画面「発信者 → 検索アルゴリズム」で「索引を作り直す」を押す（2万人で約1分。終わらなければ1時間ごとに自動で続きを作る）
2. 「学習の使い方」は「自動」のままでよい（データが少ないうちは手の重みのまま。押された記録がたまると毎晩学習し、良くなったときだけ反映）
3. 本人確認ができている確かな発信者は、発信者の編集画面で「信頼の起点にする」にチェック（つながりの信頼度の起点になる）
4. 「発信者 → 不正対策」で、順位を下げている発信者と理由を確認できる（問題なければ「問題なし」で対象外に）
5. AIの自動タグを使うときは、「記事の自動投稿」でAPIキーを入れてから、ここでオンにする（目安 1人1円前後）

### 10. フォロワー数の自動更新（公式API）
1. 管理画面「発信者 → フォロワー数の自動更新」を開く
2. **YouTube**（無料・発信者は何もしなくてよい）: Google Cloud で「YouTube Data API v3」を有効にして API キーを作り、貼り付ける
3. **Instagram・Threads・TikTok**（無料・発信者がマイページで「連携する」を押す）: 各SNSの開発者向けサイトでアプリを作り、画面に出ている「戻り先のURL」を登録して、アプリのIDと秘密の値を貼り付ける（TikTok は審査あり）
4. **X**（有料）: 使うときだけオンにし、更新の間隔と1日の上限を決める
5. 設定したものから自動で更新が始まる（1時間ごとに少しずつ）。発信者ページに「✓ 公式の数」「✓ 本人確認済み」の印と、30日の増減が出る

### 11. 月間成長レポート
毎月1日に自動で作られ、発信者に届きます（設定は不要）。日本語のフォントが必要です（「集客・回遊」の「シェア画像のフォント」）。過去の月を作り直すときは「集客・回遊」の「月間成長レポート」から。

### 12. ジャンル別のトレンド
設定は不要です。検索されるたびに、全体とジャンルごとに数えられ、`/trends/`（機能ページ「トレンド」）に X のトレンドのような順位が出ます。機能ページを作っていない場合は「集客・回遊」の「ページをまとめて作る」で作れます。出したくない言葉は、これまでどおり「表示しない言葉」に入れます。

### 13. トレンドのページ・発信者へのお知らせ・順位バッジ・診断（1.11.0）
設定は不要です（更新すると「トレンド」「発信者診断」のページが自動でできます）。
- キーワードごとのページ（`/trends/おせち/` など）は自動で増え、サイトマップにも載ります
- 発信者へのトレンドのお知らせは、「集客・回遊」の「発信者へのトレンドのお知らせ」で止められます
- 順位バッジ（カード型など）は、発信者のマイページの「シェア画像と順位バッジ」から貼り付けのHTMLをコピーできます
- 診断のページは `[sns_shindan]`。結果の画像を作るには、日本語のフォント（「シェア画像のフォント」）が必要です

### 14. 自動投稿の記事の種類とサイト内リンク（1.12.0）
「記事の自動投稿」の画面で設定します（初期はすべてオン、トレンド記事は1日1本）。
- SNS運用コラムと「ジャンル × SNS」の攻略ガイドを交互に書きため、決めた時刻に公開
- ジャンルで急上昇した言葉は、その日のうちに「トレンド記事」にしてすぐ公開
- 毎月1日に、前の月の数字から「SNSトレンドレポート」を公開
- 人気の発信者の一覧やレポートの表は、AIではなくサイトの本物のデータを差し込み
- 記事の中の言葉に、トレンドのページ・特集ページへのリンクを自動で付け、最後に「この記事に関連するページ」と発信者診断の案内（これまでの記事にも付きます）

### 15. 記事のおすすめ（1.13.0）
設定は不要です。「みんなの記事」の最初のタブが「おすすめ」になり、会員ページ・記事の下・検索結果にも出ます。管理画面「発信者 → 記事のおすすめ」で、数字・学習の結果・重み・おすすめの例（理由つき）を確認でき、「初期の重みだけを使う」にもできます。トップページなどには `[sns_for_you_articles count="5"]`。

### 16. 集客の強化（1.14.0）
更新すると「アワード」「コラボ相手探し」「似ている発信者」「ブログに貼れるランキング（/blog-parts/）」のページが自動でできます。似ている発信者のページ・構造化データ・アワード・コラボ・ブログパーツは設定不要です。
- **公式SNSへの自動投稿**:「発信者 → 公式SNSへの自動投稿」で Threads（ユーザーIDと長期トークン）・X（4つのキー。有料API）を設定。初期は「確認してから投稿」で、候補を見て1件ずつ投稿できます
- **LINE**:「発信者 → LINE連携」で、LINE公式アカウントの Messaging API のチャネルシークレット・長期トークン・ベーシックIDを入れ、画面の Webhook URL を LINE Developers に登録します。会員は会員ページ・マイページの「LINEで受け取る」から連携します

### 17. 推しリスト・質問箱・AIプロフィール診断・レベル・報道向けの発表文（1.15.0）

- **会員登録・お問い合わせなどのフォーム**（1.17.1）: サイトの表側のページでは、送り先を `/wp-admin/admin-post.php` ではなくサイトのトップのアドレス（`/?snscs_fp=1`）にしています。SiteGuard WP Plugin の「管理ページアクセス制限」や、/wp-admin/ のBasic認証があっても、ログインしていない人が会員登録できます。ページのキャッシュが古くても、開いたときにフォームの合言葉を新しくします

- **トップページの中央**（1.17.2）: 看板・創設メンバー募集（「集客・回遊」で人数を設定。初期値は先着100人、届いたら自動で消える）・SNSから探す・読みもの（今日の用語・質問箱・急上昇の言葉）・はじめての方へ・新着のマイリンク。発信者が少ないうちも空白になりません。看板の見出しと説明も「集客・回遊」で変えられます

- **すべてのページをポータルの見た目に**（1.17.3）: 「集客・回遊」の「ポータルの見た目にするページ」で、トップページだけ／このプラグインのページすべて（初期値。機能ページ・検索・マイページ・会員ページ・規約・発信者・記事・コラム）／サイト全体 から選べます。トップ以外のページは、本文と右の列（ログイン・発信者の方へ・カレンダー・トレンドワード）で表示します

## 検索API

```
GET /wp-json/snscs/v1/creators?q=料理&platform=instagram&min_followers=10000&sort=followers&page=1&per_page=20
```

| パラメーター | 意味 |
|---|---|
| `q` | キーワード（空白区切りで、すべての語を含むものを探す） |
| `platform` | `x` `youtube` `instagram` `threads` `tiktok` `substack` |
| `genre` / `region` | ジャンル・地域のスラッグ（親を指定すると子も含む） |
| `min_followers` / `max_followers` | フォロワー数の範囲 |
| `sort` | `recommended`（おすすめ順・初期値） / `followers`（多い順） / `newest`（新着順） / `name`（名前順） |
| `page` / `per_page` | ページ番号 / 1ページの件数（最大100） |

全体の件数は、応答のヘッダー `X-WP-Total` で分かります。

## 動作環境
- WordPress 6.0 以上
- PHP 7.4 以上
- MySQL 5.7 以上 / MariaDB 10.3 以上
- PHP の openssl 拡張（プッシュ通知で使う。多くのサーバーで最初から有効）
- メモリ: 毎晩の点数計算は発信者2万人で約100MB。WordPress の重い処理用の上限（既定 256MB）で5万人程度まで。それ以上は WP_MAX_MEMORY_LIMIT を増やす
- プッシュ通知は https のサイトでだけ使える
